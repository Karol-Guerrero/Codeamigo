Pagar con Mercado Pago

Falta configurar js/pago.js con tu PUBLIC_KEY y tu PREFERENCE_ID de prueba para que aparezca el botón de pago real.

Qué pasa en esta prueba

  1. El usuario paga $5.00 MXN aquí mismo, con una tarjeta de prueba de Mercado Pago (modo sandbox).
  2. Mercado Pago confirma el pago y nos da un ID de pago.
  3. Para devolver los $5.00, se ejecuta un reembolso con ese ID usando el Access Token — esto se hace desde un script aparte, nunca desde el navegador, porque el Access Token es secreto y no debe aparecer en el código de la página.
Por eso esta pantalla solo usa la Public Key (que sí es segura para el navegador). El cobro y la devolución reales se muestran desde la terminal durante la demo.
